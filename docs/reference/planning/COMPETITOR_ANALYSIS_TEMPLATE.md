## 1. 경쟁사 발굴

### 1.1 검색 채널

| 채널 | 검색 방법 | 용도 |
|------|-----------|------|
| App Store | 키워드 검색 + 관련 앱 | 직접 경쟁사 |
| Google Play | 키워드 검색 + 비슷한 앱 | 직접 경쟁사 |
| Product Hunt | 카테고리 브라우징 | 신규 경쟁사 |
| G2/Capterra | 소프트웨어 비교 | B2B 경쟁사 |
| Reddit | r/[관련주제] 검색 | 사용자 추천 |
| Twitter/X | 해시태그 검색 | 트렌드 파악 |
| Google | "[앱유형] app" 검색 | 간접 경쟁사 |

### 1.2 경쟁사 유형 분류

```
┌─────────────────────────────────────────────────────────────┐
│                     직접 경쟁사 (Primary)                    │
│        동일한 문제를 동일한 방식으로 해결하는 앱              │
│                     예: 투두앱 vs 투두앱                     │
├─────────────────────────────────────────────────────────────┤
│                     간접 경쟁사 (Secondary)                  │
│        동일한 문제를 다른 방식으로 해결하는 앱               │
│                   예: 투두앱 vs 캘린더 앱                    │
├─────────────────────────────────────────────────────────────┤
│                     잠재 경쟁사 (Tertiary)                   │
│            향후 진입 가능성이 있는 플레이어                  │
│                예: 대형 IT 기업, 인접 카테고리               │
└─────────────────────────────────────────────────────────────┘
```

## AI 분석 프롬프트 모음

### 경쟁사 발굴
```
[앱 카테고리] 분야의 주요 경쟁 앱을 찾아줘:
1. 직접 경쟁사 5개
2. 간접 경쟁사 5개
3. 각 앱의 핵심 특징
4. 다운로드 수 및 평점
5. 최근 업데이트 동향
```

### 기능 분석
```
[앱 이름]의 주요 기능을 분석해줘:
1. 핵심 기능 목록
2. 유료/무료 구분
3. 사용자가 가장 많이 언급하는 기능
4. 기능별 UX 품질 평가
5. 누락된 것으로 보이는 기능
```

### 리뷰 분석
```
[앱 이름]의 최근 리뷰를 분석해줘:
1. 긍정적 피드백 상위 5개
2. 부정적 피드백 상위 5개
3. 기능 요청 사항
4. 버그 및 성능 이슈
5. 경쟁 앱 언급 내용
```

### 차별화 전략
